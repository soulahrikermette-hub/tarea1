# Sistema de Matrícula - Grupo N°2

Proyecto académico (UTP) para practicar trabajo en equipo con GitHub: tablero Kanban, issues, ramas y Pull Requests.

## Objetivo
Construir una página web sencilla donde un alumno pueda registrarse y matricularse en cursos.

## Cómo usarlo
1. Clona el repositorio: `git clone https://github.com/soulahrikermette-hub/tarea1.git`
2. Abre `index.html` en tu navegador. No necesita instalar nada.

## Forma de trabajo
- Cada actividad es un issue con responsable, prioridad y criterio de aceptación.
- Cada actividad se trabaja en su propia rama y se integra con un Pull Request.
- Tablero: Por hacer → En proceso → En revisión → Terminado.
- Nadie puede tener 3 tareas "En proceso" a la vez.
